6 Plotly vizualizácie

6.1 Čo je plotly?

Dplyr a ggplot po svojom uvedení získali veľkú popularitu medzi ľuďmi, ktorí potrebujú upravovať dáta a následne ich vizualizovať. Pri vizualizácii sa ggplot stal go to možnosťou a s ním aj formátovanie a typ grafov, ktoré je možné vytvoriť. Tieto grafy definuje okrem iného to, že sú statické. Postupom času sa však na prezentáciu dát a analýz začali používať dynamické nástroje, ktoré ponúkajú určitú mieru interaktivity.

Plotly je spoločnosť, ktorá vytvára nástroje pre data analýzy a vizualizáciu dát. Takéto nástroje prináša pre rôzne platformy a R nie je výnimkou. V R je možné si nainštalovať a využívať plotly knižnicu, ktorá umožňuje vytvárať interaktívne grafy rôznych typov. Čo sú výhody takýchto grafov?

  1. Interaktívnosť
  • dlhodobo sa tvorili v R statické grafy
  • zmena prišla s popularizáciou dashboardov a html riešení
  • plotly dáva možnosť analyzovať dáta hlbšie ako pri použití statických grafov
  1. Upravovateľnosť a flexibilita
  • flexibilita podobná ggplotu
  • je možné upraviť množstvo prvkov grafu
  • pridávajú sa k tomu aj možnosti úpravy interaktívnych prvkov
  1. Možnosti grafov
  • ponúka veľké množstvo typov grafov

6.2 Ako plotly funguje

packages_needed <- c("dplyr", "ggplot2", "plotly", "gapminder", "palmerpenguins")

install.packages(packages_needed)

6.2.2 ggplotly

Prvým spôsobom, ako spraviť interaktívny plotly graf je jednoducho vytvoriť ggplot graf, uložiť ho do objektu a zinteraktívniť ho pomocou funkcie ggplotly.

p <- ggplot(data = penguins_df,
            mapping = aes(x = body_mass_g,
                     y = flipper_length_mm,
                     color = species)) +
     geom_point() +
     scale_color_manual(values = c("#E49C20", "#003669", "#E73230")) +
     labs(
          title = "Tučniaci, ich hmotnosť a krídla",
          subtitle = "Pozitívny vzťah medzi hmotnosťou a veľkosťou krídel",
          caption = "Dáta: Gorman, Williams & Fraser (2014)",
          x = "Hmotnosť (g)",
          y = "Dĺžka krídla (mm)",
          color = ""
   ) +
     theme_minimal()

p

ggplotly(p)

Takýmto spôsobom môžete jednoducho vytvoriť z Vašich statických grafov interaktívne. Samozrejme ich viete ďalej v plotly upravovať. Ukážme si ale, ako sa vyskladá vyššie zobrazený graf v plotly.

6.2.3 plotly graf

6.2.3.1 Vytvorenie grafu s vyobrazením dát

plot_ly(data = penguins_df,
        x = ~body_mass_g,
        y = ~flipper_length_mm,
        type = "scatter",
        mode = "markers")

Ako je vidno z kódu, tak plotly má trošku inú logiku výstavby grafu. Samozrejme treba definovať dáta a x/y os. Okrem toho je potrebné definovať, aký graf chceme z dát zobraziť. To sa robí pomocou definovania argumentu type v plot_ly funkcii. Pri bodovom grafe treba tiež definovať mode, čo je pre bodový graf markers.

Vystavať graf sa dá aj postupne za použitia add_* funkcie. Tá presne definuje, čo sa v grafe zobrazí, podobne ako pri geom_* v ggplote. Kód zároveň viete vyskladať pomocou pipes (%>%).

penguins_df %>%
  plot_ly() %>%
  add_trace(
    type = "scatter",
    mode = "markers",
    x = ~body_mass_g,
    y = ~flipper_length_mm
  )

6.2.3.2 Pridanie tretej dimenzie a úprava prvkov grafu

Pokračujme úpravou grafu tak, aby sme pridali rôzne farby pre jednotlivé kategórie, ako aj názov grafu, jeho zdroj a podobne. Tretiu dimenziu definujeme v plot_ly funkcii globálne alebo v add_* funkcii pomocou argumentu color. V argumente colors zároveň vieme zadefinovať nami vybrané farby. Na úpravu ostatných prvkov grafu použijeme layout funkciu, v ktorej špecifikujeme title (názov grafu), zmeníme názvy osí pomocou xaxis a yaxis, posunieme legendu viac do stredu a pridáme popis grafu pomocou argumetnu annotations.

penguins_df %>%
  plot_ly() %>%
  add_trace(
    type = "scatter",
    mode = "markers",
    x = ~body_mass_g,
    y = ~flipper_length_mm,
    color = ~species,
    colors = c("#E49C20", "#003669", "#E73230")
  ) %>%
  layout(
    title = list(text = "Tučniaci, ich hmotnosť a krídla",
                 xanchor = "right",
                 xref = "paper"),
    xaxis = list(title = "Hmotnosť (g)"),
    yaxis = list(title = "Dĺžka krídla (mm)"),
    annotations = list(x = 1.2, y = -0.09, 
                       text = "Dáta: Gorman, Williams & Fraser (2014).",
                       xref="paper", yref='paper', showarrow = F, 
                       xanchor="right", yanchor="auto", xshift=0, yshift=0,
                       font = list(size = 10)),
    legend = list(x = 100, y = 0.5)
  )

Ako vidíte, tak skladanie rovnakého grafu z ggplotu je vcelku náročné a preto odporúčam, ak viete grafy vytvárať v ggplote, použiť ggplotly a natívne funkcie plotly len na úpravu interaktívnych prvkov.

6.3 Stĺpcový graf

V týchto častiach si ukážeme na jednoduchých príkladoch, ako vyskladať rôzne typy grafov. Začneme stĺpcovým grafom. Pre túto ukážku použijeme upravené ESS dáta, ktoré sme využívali aj v predošlých častiach.

ess_sk <- ess_sk %>% 
  mutate(
    gndr = factor(gndr, labels = c("Female", "Male")),
    polintr = factor(polintr, labels = c("Very interested", "Quite interested", "Hardly interested", "Not at all interested",  "No answer"), ordered  = TRUE)
  )

Stĺpcový graf vytvoríme jednoducho pomocou add_bars funkcie.

ess_sk %>%
  group_by(polintr) %>%
  summarize(Počet = n()) %>%
  plot_ly() %>%
  add_bars(x = ~polintr, y = ~Počet)

Kvantifikovať počty v jednotlivých kategóriách musíte v plotly sami. Vyššie je ukázaný spôsob za využitia dplyr, ale je to možné aj v samotnom plotly pomocou funkcie transforms (je to však zložitejšie). Pokračujme však s úpravou stĺpcového grafu. Ďalšiu premennú môžeme zapracovať pomocou color argumentu. Pridajme si do grafu rozdelenie podľa genderu.

Na to, aby sme takýto graf vytvorili si musíme upraviť dáta tak, aby sme mali počty pre jednotlivé kategórie premennej polintr, ako aj premennej gndr. Následne použijeme argument color na zobrazenie stĺpcov pre jednotlivé kategórie gndr premennej.

ess_gndr <- ess_sk %>%
  group_by(polintr, gndr) %>%
  summarize(Počet = n())

fig <- ess_gndr %>%
  plot_ly() %>%

fig <- fig %>% layout(

6.4 Histogram

Po stĺpcových grafoch si môžeme ukázať aj histogramy. Vytvoríme ich pomocou add_histogram funkcie.

gapminder_df %>%
  plot_ly() %>%
  add_histogram(x = ~lifeExp)

Zmeniť vieme znova argumentom marker a color.

gapminder_df %>%
  plot_ly() %>%
  add_histogram(x = ~lifeExp, marker = list(color = "green"))

Keď chceme porovnať histogramy, tak je najjednoduchšie zobraziť ich pre viaceré kategórie vedľa seba. To vieme spraviť pomocou funkcie subplot. Najprv si však musíme dáta zoskupiť na základe svetadielu. Následne použijeme do funkciu, ktorá vytvorí separátne grafy pre jednotlivé svetadiely a uloží ich do objektu p. sublot funkcia ich následne spojí do jedného grafu, pričom osi budú mať rovnaký rozsah vďaka argumentom shareX a shareY, ktoré sú nastavené na hodnotu TRUE. Okrem toho pridáme pomocou layout funkcie a legend argumentu názov legendy. Na záver vytvoríme spoločný názov pre x os.

fig2 <- gapminder_df %>%
          group_by(continent) %>%
          do(p=plot_ly(., x = ~lifeExp, name =~continent, type = "histogram")) %>%
          subplot(nrows = 1, shareX = TRUE, shareY = TRUE, titleX = FALSE) %>%
          layout(
            legend=list(title=list(text="<b> Svetadiel </b>"),
                        x = 100, y = 0.5)
          )

fig2 %>%
  add_annotations(
    text = "Stredná dĺžka života",
    x = 0.5,
    y = 0,
    yref = "paper",
    xref = "paper",
    xanchor = "center",
    yanchor = "bottom",
    yshift = -35,
    showarrow = FALSE,
    font = list(size = 15)
  )

Porovnanie v rámci spojeného grafu sa dá spraviť takto:

gapminder_df %>%
  plot_ly() %>%
  add_histogram(x = ~lifeExp, color = ~continent)

6.5 Bodové grafy

Bodové grafy sme si pri ggplote ukazovali dva rôzne a to také, ktoré ukazovali určité množstvá a zároveň také, ktoré ukazovali vzťahy x~y. Pri plotly si ukážeme obe verzie takýchto jednoduchých grafov. Začneme s prvým typom.

Z datasetu vyberieme len krajiny z americk0ho svetadielu za roky 1987 a 2007. Upravíme premennú year a country aby sa v grafe zobrazovali správne. Následne použijeme plot_ly a add_markers funkciu na zobrazenie grafu.

gapminder_americas <- gapminder_df %>% 
  filter(continent == "Americas", year %in% c(1987, 2007)) %>% 
  mutate(year = as.factor(year),
         country = as.character(country))

gapminder_americas %>%
  plot_ly(x = ~lifeExp, y = ~reorder(country, lifeExp)) %>%
  add_markers(color = ~year)

Keď chceme jednotlivé body spojiť, tak musíme použiť trochu komplikovanejší postup. Najprv zoskupíme dáta a v rámci funkcie plot_ly zadefinujeme x a y os pre celý graf. Následne pomocou add_trace funkcie pridáme najprv čiary (mode = "lines") a potom body (mode = "markers"). V rámci argumentov doplníme farby bodov aj čiar. Okrem toho v layout funkcii upravíme názvy osí a posunieme legendu na spodok grafu.

gapminder_americas %>%
  group_by(country) %>%
  plot_ly(x = ~lifeExp, y = ~reorder(country, lifeExp)) %>%
  add_trace(type = "scatter",
            mode = "lines",
            showlegend = F,
            line = list(
              color = "black"
            )) %>%
  add_trace(type = "scatter",
            mode = "markers",
            color = ~year) %>%
  layout(
    legend =list(orientation='h', 
                 yanchor='bottom',
                 xanchor='center', 
                 y=-0.25, x=0.5,
                 title=list(text="Rok")),
    xaxis = list(title = "Stredná dĺžka života"),
    yaxis = list(title = "Krajina"))

Pozrime sa teraz na graf zobrazujúci vzťah medzi x a y. Zobrazme si vzťah medzi HDP na obyvateľa a strednou dĺžkou života z gapminder datasetu.

gapminder_df %>%
  plot_ly(x = ~gdpPercap) %>%
  add_markers(y = ~lifeExp)

Pridajme logaritmus na gdpPercap premennú, aby sme sa dostali k lepšiemu zobrazeniu dát.

gapminder_df %>%
  plot_ly(x = ~log(gdpPercap)) %>%
  add_markers(y = ~lifeExp)

Nakoniec si pridajme trendovú krivku, korá nám bude zobrazovať lineárnu regresiu v dátach. Ak si pamätáte, tak v ggplote sme takúto krivku pridali jedonduchou funkciou geom_smooth. Pri plot_ly je tento postup zložitejší. Najprv si musíme vytvoriť model, ktorý chceme zobraziť. Následne si vytvoríme dataset s pôvodnými hodnotami strednej dĺžky života. Potom k nemu pridáme predikované hodnoty a ich štandardné chyby. Nakoniec vytvoríme plotly graf. V ňom zadefinujeme x os ako logaritmus HDP na obyvateľa, pridáme body, ktoré definujú súradnice HDP na obyvateľa a strednej dĺžky života, pričom sú farebne odlíšené na základe svetadiela. Taktiež pridáme trendovú čiaru a jej štandardné chyby a na záver upravíme názvy osí a posunieme legendu (pričom legendy pre trendovú čiaru a štandardné chyby schováme).

fit <- lm(lifeExp ~ log(gdpPercap),data=gapminder_df)
fitdata <- data.frame(gdpPercap = gapminder_df$gdpPercap)
prediction <- predict(fit, fitdata, se.fit=TRUE)
fitdata$fitted <- prediction$fit


fitdata$ymin <- fitdata$fitted - 1.96*prediction$se.fit
fitdata$ymax <- fitdata$fitted + 1.96*prediction$se.fit


gapminder_df %>%
  plot_ly(x = ~log(gdpPercap)) %>%
  add_markers(x = ~log(gdpPercap), y = ~lifeExp,
              color = ~continent) %>%
  add_trace(data = fitdata , x = ~log(gdpPercap), y = ~fitted, 
            mode = "lines", 
            type = "scatter",
            name = "",
            line =list(
              color="#8d93ab"),
            showlegend = F
  ) %>%
  add_ribbons(data = fitdata, ymin = ~ ymin, ymax = ~ ymax,
              name = "",
              line = list(
                color="#F1F3F8E6"
              ),
              fillcolor ="#F1F3F880",
              showlegend = F) %>%
  layout(
    xaxis = (list(title = "HDP na obyvateľa (log)")),
    yaxis = (list(title = "Stredná dĺžka života")),
    legend = list(x = 100, y = 0.5)
  )

Hranice v rámci dát sa v plotly dajú zobraziť dvoma základnými spôsobmi. Prvým je použitie add_segment funkcie. kde je nutné definovať začiatok a koniec čiar.

gapminder_df %>%
  plot_ly(x = ~log(gdpPercap)) %>%
  add_markers(x = ~log(gdpPercap), y = ~lifeExp,
              color = ~continent) %>%
  add_segments(x = ~mean(log(gdpPercap)), xend = ~mean(log(gdpPercap)),
               y = ~min(lifeExp), yend = ~max(lifeExp),
               showlegend = F,
               line = list(
                 color = "black",
                 dash = "longdash"
               )) %>%
  add_segments(x = ~min(log(gdpPercap)), xend = ~max(log(gdpPercap)),
               y = ~median(lifeExp), yend = ~median(lifeExp),
               showlegend = F,
               line = list(
                 color = "black",
                 dash = "dashdot"
               )) %>%
  layout(
    xaxis = (list(title = "HDP na obyvateľa (log)")),
    yaxis = (list(title = "Stredná dĺžka života")),
    legend = list(x = 100, y = 0.5)
  )

Ako vidíte, tak čiary zostávajú pri odzoomovaní grafu na svojom mieste a neprispôsobujú sa interaktívnej manipulácii. Na to treba vytvoriť dve funkcie, ktoré následne použijeme v rámci layout funkcie.

vline <- function(x = 0, color = "red", dash = "longdash") {
  list(
    type = "line", 
    y0 = 0, 
    y1 = 1, 
    yref = "paper",
    x0 = x, 
    x1 = x, 
    line = list(color = color,
                dash = dash)
  )
}

hline <- function(y = 0, color = "blue", dash = "dashdot") {
  list(
    type = "line", 
    x0 = 0, 
    x1 = 1, 
    xref = "paper",
    y0 = y, 
    y1 = y, 
    line = list(color = color,
                dash = dash)
  )
}


gapminder_df %>%
  plot_ly(x = ~log(gdpPercap)) %>%

              color = ~continent) %>%
  layout(
    shapes = list(vline(~mean(log(gdpPercap))), hline(~median(lifeExp))),
    xaxis = (list(title = "HDP na obyvateľa (log)")),
    yaxis = (list(title = "Stredná dĺžka života")),
    legend = list(x = 100, y = 0.5)
  )

6.6 Boxplot

Boxploty a ich užitočnosť pri analýze deskriptívnych dát sme si ukazovali už viackrát. Ako sa ale dajú vytvoriť interaktívne boxploty?

penguins_df %>%
  plot_ly() %>%
  add_boxplot(x = ~species, y = ~body_mass_g)

Interaktívny graf nám po prejdené myšou na jeden z boxplotov ukáže, aké hodnoty nadobúdajú základné ukazovatele. Pridajme si ešte jednotivé body, ktoré reprezentujú hodnoty v rámci kategórií. Na to nám poslúži argument boxpoints = "all". Rozpätie bodov nastavíme pomocou argumentu jitter a ich poz9ciu v grafe pomocou argumentu pointpos.

penguins_df %>%
  plot_ly() %>%
  add_boxplot(x = ~species, y = ~body_mass_g,
              color = ~species,
              boxpoints = "all", jitter = 0.3, pointpos = -1.5,
              showlegend = F)

Zujímavým pohľadom na distribúciu dát sú aj violin grafy. Tie okrem samotného boxplotu zobrazujú kernel density odhad (kernel density estimation - kde), ktorý v zásade zobrazuje distribúciu dát a hovorí o tom, aká je pravdepodobnosť, že pozorovanie bude nadobúdať určitú hodnotu. Violin graf zobrazíme pomocou add_trace funkcie, kde typ grafu špecifikujeme ako violin. Okrem toho argumentom box = list(visible = T) zobrazíme v grafe aj boxplot a argument meanline nastavíme tak, aby sa nám zobrazila prerušovaná čiara pre priemer.

penguins_df %>%
  plot_ly() %>%
  add_trace(
    y = ~body_mass_g,
    type = 'violin',
    box = list(
      visible = T
    ),
    meanline = list(
      visible = T
    ),
    x = ~species,
    color = ~species,
    showlegend = F)

6.7 Čiarový graf

Posledným grafom, ktorý si ukážeme je čiarový. Ide o graf, ktorého argumenty sme používali už aj v predošlých príkladoch, čiže nemalo by ísť o nič zásadne nové. Na vytvorenie čiarového grafu použijeme funkciu add_lines. Aby sa nám graf zobrazil správne, tak musíme dáta najprv zoskupiť na základe firmy, z ktorej pochádzajú.

stocks %>%
  group_by(company) %>%
  plot_ly() %>%
  add_lines(x = ~date, y = ~stock_index)

Interaktívnosť plotly nám umožňuje zvýraznenie nejakej z čiar iným spôsobom ako to bolo pri ggplote. Ukážme si ako sa zvýrazní jedna z čiar po prejdení na nej myšou. Na toto budeme potrebovať spraviť viacero vecí. Prvou je, že si zadefinujeme kľúč, na základe ktorého sa budú čiary zvýraňovať. To je možné prostredníctvom funkcie highlight_key, kde ako kľúč definujeme premennú company. Následne vytvoríme plotly objekt, v ktorom nezadefinujeme žiadnu zobrazovaciu vrstvu, iba farbu čiar a ich zoskupenie. Takýto objekt použijeme na vytvorenie čiarového grafu s premennými, ktoré sme už zadefinovali vyššie. Nakoniec použijeme funkciu highlight, kde zadefinujeme ako objekt v predošlom kroku vytvorený graf a argumenty zobrazovania.

# zadefinujme company ako highlight kľúč
st <- highlight_key(stocks, ~company)

# vytvorme plotly objekt
base <- plot_ly(st, color = I("black")) %>% 
  group_by(company)

# vytvorme čiarový graf
time_series <- base %>%
  group_by(company) %>%
  add_lines(x = ~date, y = ~stock_index)

# nastavme zvýraznenie
highlight(
  time_series, 
  on = "plotly_hover",
  off = "plotly_doubleclick",
  selectize = FALSE, 
  dynamic = FALSE,
  color = "red",
  persistent = FALSE
)
